The MATLAB "MoRiverMultiBeamData.mat" data structure required to run the analysis and plotting scripts in the Multibeam Results folder can either be obtained by downloading from (https://doi.org/10.5281/zenodo.17095588) or processing from (dr_FreeMoExportData.m). It was too large to be included within the repo. Once obtained, it should be placed in the following directory: (".\FreeMoRiv\MATLAB\RiverBedformAnalysisAlgorithms\AlgorithmResultsMultibeam\"). If downloaded with the DOI, this is the final step and all driver scripts should work as intended. If processed via the Export Data script, one more step is required. Once the data structure is within the specified folder, a removal script should be run called (dr_DiscardBadSurveys.m). Once run, the dataset is complete and ready to use.
